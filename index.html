Sobre mí

Soy Ingeniero de Software apasionado por construir productos digitales que resuelvan problemas reales.

Trabajo con Python, JavaScript, React y FastAPI para crear sistemas eficientes y escalables, desde el diseño de interfaces hasta la arquitectura del backend. He integrado APIs externas como Google Calendar y Outlook Calendar, implementado autenticación OAuth 2.0 y conectado servicios de inteligencia artificial para procesamiento de lenguaje natural.

Tengo experiencia desarrollando PWAs con Service Workers e IndexedDB, notificaciones en tiempo real con Web Push (VAPID), síntesis de voz (TTS), tareas programadas con APScheduler, pasarelas de pago y sistemas de caché para optimización del rendimiento.

Utilizo GitHub Actions para CI/CD con despliegues automatizados en Railway y Vercel. Aplico metodologías ágiles, XP y desarrollo incremental con arquitectura en tres capas.

MVP Completado

Scolyax

Plataforma de productividad académica potenciada con IA. Incluye a Iris, un agente inteligente que resume documentos y crea tareas automáticamente. Implementa técnicas de estudio como Pomodoro, Flowtime y 52/17 con bloqueo de distracciones, un test cognitivo VARK para personalizar el aprendizaje, gamificación con sistema de XP y logros, y un modo crisis para momentos de sobrecarga académica. PWA instalable construida con React, FastAPI, PostgreSQL e integración con Gemini.

React FastAPI PostgreSQL Gemini AI PWA Docker Gamificación XP Test VARK IA / NLP
02
En Operación

Gestión de Taller

Sistema de escritorio para talleres mecánicos de motos, desarrollado en Python. Permite registrar vehículos, dar seguimiento al estado de cada reparación y gestionar el inventario de piezas, generando recibos en PDF automáticamente. Cuenta con interfaz gráfica de tema oscuro, base de datos SQLite local, y se distribuye como ejecutable independiente para Windows.

Python SQLite Generación de PDF GUI de escritorio Tema oscuro Windows .exe Gestión de inventario
03
En desarrollo

FluxPay

Pasarela de pagos end-to-end integrada con Wompi. Soporta Tarjeta, Nequi y PSE con cifrado SHA-256 para firmas de integridad y tokens de aceptación por transacción. Backend en Node.js + Express.js protegido con Helmet.js y rate limiting. Incluye panel de administración con métricas en tiempo real, filtros por estado y email, historial paginado e impresión de facturas.

Node.js Express.js HTML5 · CSS3 · JS Vanilla Wompi API SHA-256 Helmet.js Rate Limiting CORS Axios
